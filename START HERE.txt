MINIMAX ASSET TOOL - START HERE
================================

Easiest installation (recommended)
----------------------------------

1. Double-click "Install MiniMax Asset Tool.cmd".
   - If you downloaded ZIP parts (.part1.zip, .part2.zip, ...), keep the CMD, every
     part, and ALL signature files together in one folder: the .sha256 manifest,
     the .sha256.minisig signature, minisign.pub, and minisign.exe. The installer
     verifies the signature and every file, and refuses to start if any file is
     missing.
   - If this folder is already extracted, just run the CMD here.
2. Let the installer finish.
3. Wait for the app to open, enter your MiniMax API key, and choose an output folder.

The installer works only for your Windows account. It does not ask for administrator
access. It copies the app to your local Programs folder and creates Desktop and Start
menu shortcuts.

You do not need 7-Zip or another archive program for the easy installation.

Everything needed for local processing is already included: the application runtime,
FFmpeg, Real-ESRGAN, ONNX Runtime, Sharp, and all supported local models. Nothing else
needs to be downloaded during normal use. An internet connection is still required
when you ask MiniMax or another cloud provider to generate an asset.

Portable use
------------

If you do not want to install it, keep the extracted folder together and double-click
"MiniMaxAssetTool.exe". Do not move only the EXE; it needs the resources folder beside it.

Windows security message
------------------------

This release does not yet carry a new project Authenticode signature. Its
integrity is protected by a published SHA-256 inventory manifest with a detached
Minisign signature, which the installer verifies before extracting anything.
Download releases only from the official Ceegore GitHub repository and compare
the download with the published SHA-256 manifest.

The final legacy-compatible 1.0.x release keeps the previously validated
Windows runtime binaries byte-identical and updates the application content
through Electron's app.asar package. This is a temporary transition mechanism,
not the long-term release model. Future releases are being prepared for managed
Authenticode signing.

Never disable Microsoft Defender, SmartScreen or Smart App Control and never
add a Defender exclusion for this app. Do not run files whose signature or
checksums do not match. A work or school computer may enforce a policy that
only its administrator can approve; the installer does not try to bypass that
policy.
