# Documentation

These files explain the parts of the project that are needed to maintain, test, and release the application.

| File | Purpose |
|---|---|
| `DECISIONS_AND_RULES.md` | Start here. Architecture, security, state, packaging, and coding rules. |
| `ARCHITECTURE.md` | Process boundaries, module layout, data flow, persistence, and quality gates. |
| `ipc-contracts.md` | Source of truth for every `window.api` IPC channel and response shape. |
| `RELEASE.md` | Windows release checklist and artifact verification procedure. |
| `GITHUB_RELEASE.md` | Ready-to-use GitHub repository description and release text. |

The root [README](../README.md) is the end-user overview. Keep implementation details here so the project page stays focused on the workflow and benefits.
